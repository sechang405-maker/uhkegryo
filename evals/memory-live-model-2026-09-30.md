# 대화 기억 실제 모델 평가 시도 — 2026-09-30

- 모델: `google/gemma-3-4b-it` (현재 `.env` 설정). Prompt: `uhkegryo-interpreter-v0`.
- 입력: `memory.jsonl`의 MEM-01~MEM-08을 바탕으로 만든 합성 대화 맥락. 실제 사용자 기록은 전송하지 않았다.
- 결과: 해석 3회, 회상 분류 6회, 회상 답변 3회가 모두 OpenRouter의 `LLMRateLimited`(upstream 429)로 실패했다. 의미 정확성·인용 적절성의 통과 점수는 **미산정**이다.
- 예비 분류 호출 1회는 응답을 받았지만, 이력이 없는 "아까 추천한 포즈" 질문에 `role=body`를 반환했다. 평가셋 맥락 없이 실행한 호출이므로 MEM 항목의 판정에는 포함하지 않았다.
- 로컬 PostgreSQL과 fake adapter를 사용한 결정론 테스트는 별도로 292개 통과했다. 이는 실제 모델 품질 검증을 대체하지 않는다.

PR #73의 검증 범위는 백엔드 연결과 결정론적 계약 검사다. 평가 재개 시 같은 모델과 Prompt로 MEM-01~MEM-08을 실행하고, 조건 수정·회상 범위·원본 인용의 의미 일치를 각 항목별로 사람이 판정해야 한다. 서비스 품질이나 운영 적용 여부는 그 결과가 남기 전까지 판단하지 않는다.
