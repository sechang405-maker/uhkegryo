# 핀 실패와 미리보기 복구

- 결과 없음, 일시 장애, 접근 제한, 요청 한도, 만료된 미리보기를 구분한다. 기존 상태 enum을 유지하고 선택적 실패 원인·대기 시간 필드를 추가한다. 과거 저장 결과도 읽을 수 있다.
- 검색의 네트워크 장애와 429/500/502/503/504만 최대 한 번 자동 재시도한다. 명시적인 provider 일시 오류도 같은 제한을 따른다. 접근 제한, 잘못된 응답, 빈 검색은 자동 재시도하지 않는다.
- `Retry-After` 초·HTTP 날짜를 따른다. 2초를 넘는 대기는 자동 실행하지 않고 수동 재시도도 해당 카드의 대기 시간까지 막는다. Widget 조회 역시 한 번만 재시도하며 긴 대기는 해당 핀의 제한된 메모리 캐시에 보관한다.
- e1 핀의 썸네일 캐시가 만료되거나 API 재시작으로 사라지면 `expired`로 응답한다. 다시 불러오기는 고정 카드 검색을 실행하므로 원래 검색과 결과가 달라질 수 있다. DB에 썸네일 URL을 저장하지 않는다.
- 미리보기 복구는 기존 정상 핀을 보존하고 새 정상 결과를 최대 8개까지 채운다. 결과 없음·전체 실패는 기존 결과를 그대로 유지한다. 일부 핀 실패가 다른 핀을 지우지 않는다.
- 삭제·접근 제한 핀에는 재시도 버튼 대신 검증된 ID로 만든 Pinterest 원문 링크를 제공한다. 이미지 로딩 자체가 실패한 경우 브라우저는 원인을 확정할 수 없어 일반 안내와 다시 불러오기를 제공한다.

검증: 재시도 횟수, 403/404 무재시도, Retry-After 및 수동 클릭 대기, 부분 성공, 캐시 만료, 안전한 원문 링크 단위 테스트. 브라우저 fixture에서 만료 복구·정상 결과 보존·빈 결과·503·403·429·모바일을 검증한다. 실제 공개 검색은 별도로 확인하며 유료 생성 API와 사용자 기록 쓰기는 사용하지 않는다.
