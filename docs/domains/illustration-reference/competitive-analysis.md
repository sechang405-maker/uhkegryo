# 경쟁 서비스 분석

> 조사 기준일: 2026-09-21. 이 문서는 공개 시작 흐름을 비교한 질적 조사이며, 전체 기능·성능 순위·사용성 실험을 주장하지 않는다.

테스트 문장은 “아래에서 올려다 보는 느낌으로 힙한 스타일의 포즈를 그리고 싶은데 광각으로 그리고 싶어.”였다. 이 문장은 `low angle`, `foreshortening`, `wide-angle perspective`처럼 서로 다른 역할의 후보로 나뉠 수 있지만, “힙한”만으로 표준 포즈를 확정할 수는 없다.

| 경쟁군 | 관찰한 시작 흐름 | 사용자가 여전히 해야 하는 일 | UH케그려의 좁은 역할 |
| --- | --- | --- | --- |
| 범용 LLM (ChatGPT·Claude·Gemini) | 자연어 설명 또는 이미지 생성·긴 설명을 제공할 수 있다. | 설명에서 필요한 용어를 고르고 검색어와 역할로 다시 바꾼다. | 허용 term ID·근거·역할만 구조화하고 결정론 검증을 적용한다. |
| Pinterest | 긴 자연어 검색은 결과가 지나치게 넓거나 0건일 수 있으며, 자동 역할 분리는 관찰되지 않았다. | 짧은 전문 검색어를 직접 만들고 여러 검색을 조합한다. | 선택된 역할에 한해 JSON 카드의 검색 조각으로 탐색 계획을 만든다. |
| 제스처 연습 (Line of Action·Quickposes) | 연습 유형·시간·포즈 범주를 먼저 수동 선택하는 흐름이다. | 어떤 포즈나 조건을 연습할지 스스로 번역해 선택한다. | 포즈 연습 도구를 대체하지 않고, 시작 전에 요구를 용어로 정리한다. |
| 3D 포저 (PoseMy.Art·Magic Poser) | 모델·카메라·FOV·포즈를 직접 조작하는 흐름이다. | 체형·시점·원근 조건과 조작값을 직접 결정한다. | 3D 제작을 대체하지 않고, 초보자가 조작 전에 필요한 조건을 분리한다. |

서비스는 한 장의 정답 이미지나 화풍 복제를 제공하지 않는다. 일상어를 검수된 전문용어와 관찰 기준으로 바꾸고, 사용자가 외부 Pinterest 원본을 직접 탐색하도록 돕는다. LLM은 허용 term ID 후보만 만들고 카드 검증·검색어 조립·URL 인코딩은 결정론 코드가 담당한다.

따라서 차별점은 “Pinterest보다 더 많은 이미지를 찾는다”가 아니라 **모호한 문장을 검증된 기초 드로잉 용어와 필요한 역할만의 탐색 계획으로 바꾼다**는 데 있다. 서버는 그 계획의 `query_fragments`에 고정 검색 제한어를 붙여 SearXNG Pinterest 엔진 검색을 수행하고, 반환 URL의 Pin ID를 검증한 뒤 widget 조회를 수행한다. 이미지 재게시와 외부 어휘 자동 주입은 범위 밖이다.
