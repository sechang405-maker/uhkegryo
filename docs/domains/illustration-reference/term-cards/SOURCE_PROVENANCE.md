# TERM_CARD 출처·검수 기록

`index.json`과 index가 선언한 역할별 JSON은 팀이 관리하는 TERM_CARD의 런타임 원본이다. 앱 시작 시 구조를 검증하고 활성 카드를 메모리에 로드한다. 카드 수는 고정 계약이 아니다.

카드 데이터는 팀 검수 용어·설명·선택 조건·검색 조각만 가진다. Getty AAT, 외부 어휘 결과, Pinterest 이미지·Pin 본문·썸네일 URL·제3자 이미지는 저장하지 않는다.

카드 변경은 JSON 수정, 사람 검수, API 계약·Skill·평가셋 영향 검토, PR, 배포 순서로 수행한다.

## 2026-09-23 · Booru 태그 체계 참고 실험과 검수 카드 8개 승격

일반 영문 태그를 조사하는 Booru-Pictag 계열의 방식을 새 용어 후보를 생각하는 참고로만 사용했다. 공개 autocomplete 조회는 검증하지 못했으므로 외부 서비스는 데이터 출처나 런타임 의존성이 아니며, 원시 응답·게시물·이미지·프롬프트·작가·캐릭터·저작권 태그는 저장하지 않았다.

사람 검수를 마친 `pose` 6개와 `view` 2개를 역할별 런타임 JSON과 `index.json`의 `active_term_feedback`에 추가했다. 활성 카탈로그는 74개에서 82개가 되었고, 임시 후보 감사 JSON은 승격 뒤 보존하지 않는다.

승격한 활성 카드에는 팀 작성 용어·설명·선택 조건·검색 조각·초보자 UX만 복사했다. 외부 조회 상태, 게시물·이미지·위키·프롬프트·작가·작품·인물 태그는 런타임 카탈로그에 복사하지 않았다.

이번 변경은 로컬 JSON 데이터와 문서의 정적 검증만 포함한다. backend 카탈로그 loader, MCP `get_active_term_card`, LLM 허용 ID 검증, Pinterest URL 생성과 평가 실행은 별도 구현·검증 대상이다.
