# Illustration Reference Domain Profile

UH케그려는 캐주얼 캐릭터 일러스트의 체형·포즈·시점·원근·구도 표현을 팀 검수 TERM_CARD로 해석하는 텍스트 서비스다. 입력은 1~500자 자연어이며, 출력은 검증된 용어·근거·확인 지점·Pinterest 탐색 결과 또는 질문이다.

| 항목 | 도메인 근거와 제품 반영 |
| --- | --- |
| 당사자 경험 | 오세창은 프리랜서 캐주얼 캐릭터 일러스트레이터로 약 3년 활동했다. 텍스트 의뢰에서 캐릭터의 체형·포즈·구도를 먼저 해석하고, 한 장의 완벽한 자료 대신 세 장 이상 레퍼런스를 병렬로 열어 러프를 시작했다. |
| 반복 병목 | 초보자와 의뢰인은 “한쪽 다리에 힘을 준 자연스러운 자세”, “아래에서 올려다보는 장면”처럼 말하지만, `contrapposto`, `low angle`, `foreshortening` 같은 탐색어와 역할을 알기 어렵다. |
| 작업 순서 | 체형/소체 → 지지점·포즈 → 시점·원근·배치 → 선화 이후 세부 순서로 조건을 나눈다. 체형은 다른 조건을 해석할 때 우선 확인하는 축이다. |
| 제품 경계 | 서비스는 이미지 생성·분석·저작권 판단·정답 이미지 추천을 하지 않는다. 선택된 역할의 텍스트 설명과 외부 탐색 계획만 제공하고, 사용자가 원 출처에서 레퍼런스를 확인한다. |
| 검증 상태 | 위 작업 흐름은 당사자 도메인 경험에 근거한다. 목표 초보자의 빈도·시간 절감·사용성은 아직 인터뷰로 측정하지 않았으므로 평가셋과 소규모 과제 관찰에서 검증할 가설이다. |

도메인 용어 원본은 `index.json`과 역할별 TERM_CARD JSON 카탈로그다. 외부 어휘 조회·Getty 데이터·이미지 바이트 수집은 런타임에 사용하지 않는다. 서버는 SearXNG Pinterest 엔진 검색과 widget 이미지 URL 조회를 응답 조립에만 사용하며, 이미지 바이트·`thumbnail_url`·Pin 본문 등 부가 메타데이터를 저장하거나 LLM 입력에 사용하지 않는다. `pin_id`, `pin_url`, `status`는 세션·job 이력의 결과 필드로만 유지한다.
