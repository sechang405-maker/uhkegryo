# 기본 다크 테마

2026-10-14 개인 프런트 변경. 기존 레이아웃·서체·기능을 유지하며 기본 테마만 변경한다. 테마 전환 기능은 추가하지 않는다.

## 디자인

`frontend-design` 스킬을 적용했다. 캐릭터 레퍼런스를 보는 작업 화면에 맞춰 차콜 바탕과 구분되는 카드 표면을 사용하며 기존 분홍 브랜드 색, 방사형 용어 관계도와 배치는 유지한다. 밝은 배경 그라데이션을 단색 표면으로 교체하고 화면 색을 CSS 변수로 통일한다.

- 배경 `#18191c`, 표면 `#222429`, 카드·입력 관련 표면 `#2c2e34`
- 본문 `#f2eff2`, 보조 글자 `#c0b9c3`, 테두리 `#827c89`
- 강조 `#ff8fa8`, 강조 위 글자 `#291820`, 오류 `#ffb3aa`, 포커스 `#ffd2df`
- `color-scheme: dark`와 브라우저 theme-color를 선언한다. 이미지 자체를 어둡게 변조하지 않는다.

## 확인

- 프런트 기존 테스트 77개 통과. 최종 live production 빌드 통과.
- 별도 로컬 브라우저에서 모든 API를 합성 응답으로 가로채고 외부 요청을 차단했다. 실제 모델·검색·사용자 대화·DB에 접근하지 않았다.
- 홈, 채팅, 입력, 사이드바, 레퍼런스 카드, 확대 모달, 검색 로딩·오류, 입력 오류·보존, 비활성 버튼, 삭제 확인 취소·삭제 실패 상태를 확인했다. 모달 Escape 닫기와 트리거 포커스 복귀를 확인했다.
- 1440px 데스크톱과 390px 모바일을 시각 확인하고 320px에서 가로 넘침 없음을 확인했다. reduced-motion에서 카드 전환 시간은 0초다.
- 대비 계산: 가장 밝은 기본 강조 표면 위 보조 글자 6.44:1, 강조 글자 5.72:1, 강조 버튼 글자 7.82:1. 카드 표면과 테두리 3.36:1. 입력 포커스는 3px 윤곽선으로 확인했다. 비활성 요소는 기존 opacity와 disabled 동작을 유지한다.
- 삭제 확인은 기존 `window.confirm`이다. 확인/취소 동작을 검증했으며 네이티브 창의 구체적인 색은 브라우저·운영체제가 관리한다. 앱 CSS로 임의 교체하지 않았다.

스크린샷은 작업 폴더의 `output/playwright/dark-*.png`에 저장했다. 공개 서비스 배포는 하지 않았다. 로컬 프런트 3100에 적용했으며, 당시 8000 API가 종료되어 있어 실제 대화 기능의 재연결은 별도 API 실행이 필요하다. 대기 작업의 실제 모델 호출을 피하기 위해 API 워커는 재시작하지 않았다.
