# 카드별 답변 표시

성공·부분 성공 응답의 `reference_plan.terms`를 순서대로 표시한다. 각 항목의 검증된 `label_ko`는 Markdown `##`와 같은 의미의 h2 제목이며, 같은 항목의 `plain_meaning_ko`와 `selection_reason`을 바로 아래에 둔다. 모델의 문장을 카드별로 추측해 분리하지 않는다. 기존 `answer_text`는 별도 **종합 설명**에 보존한다.

제목은 24px, 본문은 16px이며 기존 다크 테마 색상과 글꼴을 사용한다. 긴 제목은 줄바꿈한다. 레퍼런스 보기·검색·확인 질문·재시도 버튼은 기존 동작을 유지한다.

프롬프트·API·DB 형식은 변경하지 않는다. 새 답변과 카드 데이터가 있는 과거 저장 답변 모두 새 표시를 적용한다. 카드 데이터가 없는 과거 일반 답변은 원문 Markdown을 그대로 표시한다. 카드 미선택·확인 질문·실패·기억 답변에는 카드 제목을 만들지 않는다. 저장 데이터를 수정하거나 모델에 재생성을 요청하지 않는다.

카드 제목은 React가 일반 텍스트로 escape한다. 설명은 기존 `react-markdown`의 태그 허용 목록과 `skipHtml`을 사용하며 raw HTML, script, iframe, 이미지, 클릭 가능한 링크를 허용하지 않는다. 모델이 쓴 제목은 카드 제목으로 승격하지 않는다.

검증은 합성 응답으로 다중·단일 카드, 기존 저장 구조, 카드 없는 답변, 질문, 실패, 악성 Markdown을 다룬다. 실제 Luna 호출은 필요하지 않다.
