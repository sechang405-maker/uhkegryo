# 홈 용어 3D 그래프

## 설계와 구현 계획

기존 14개 검수 예시와 5개 카테고리를 그대로 사용한다. 그래프의 연결선은 카테고리 소속만 뜻한다. 용어 사이의 의미 관계나 추천 순위를 생성하지 않는다. 기존 검색, 이미지, 이력, 모델 계약은 변경하지 않는다.

지정된 llm-brain의 `wiki_app/static/app.js:renderMiniGraph`는 MIT 라이선스의 native SVG 2D 원형 그래프였다. 정적 앱을 합성 데이터로 확인했다. 노드 탐색 개념만 참고하며 소스나 개인 지식 데이터는 복사하지 않는다.

Three.js/WebGL 엔진과 CSS-only 장식 회전을 검토했으나, 작은 그래프에 맞게 실제 XYZ 좌표를 회전·원근 투영하는 SVG 선과 HTML 버튼을 선택했다. 추가 의존성, 외부 리소스, GPU 요구, 지속 animation loop가 없다. 조작·크기 변화 때만 React가 렌더한다. 카테고리는 분홍색, 예시는 기존 표면·글자색으로 구분한다. 기존 글꼴과 브랜드 토큰을 유지한다.

- `lib/term-graph.mjs`: 유효 노드/소속 연결선, 결정적 XYZ 배치, 회전·투영, 중복 없는 다중 선택과 입력 추가. 순수 함수 테스트를 먼저 작성한다.
- `components/TermGraph.jsx`: 회전, 확대/축소, 초기화, 포인터/터치, 키보드, 설명, 복수 선택과 목록 보기. Tab/Enter로 모든 용어를 선택할 수 있으며 방향키로 시점을 이동한다. 확대 버튼과 목록은 핀치 조작 없이도 이용 가능하다. 자동 운동은 없다.
- `app/page.jsx`: 기존 홈 블록만 대체하고 선택 ID를 부모에 보관한다. 설명 열람과 명시적 검색을 구분한다. 입력 추가는 기존 초안을 보존하며 500자 제한을 넘기지 않는다.
- `app/globals.css`: 그래프 전용 스타일. 작은 화면에서는 노드와 선택한 라벨에 집중하고 목록에서 전체 이름을 제공한다. 움직임 감소 환경에도 자동 애니메이션이 없으며 전환 효과를 넣지 않는다.

검증: 유효한 14개 노드/소속 관계, 깊이에 따른 좌표 변화, 같은 역할 복수 선택, 중복 추가와 길이 제한의 단위 테스트. 기존 전체 프런트 테스트와 demo/live production 빌드. 브라우저로 메인·회전·줌·설명·복수 선택·입력 보존·검색·이력·모바일·키보드·목록·WebGL 비활성·reduced motion을 확인하고 스크린샷을 검토한다. 좁은 로컬 mock 서버만 사용하고 실제 모델/DB를 호출하지 않는다.

검증 완료 후 개인 main에 명시적 변경 파일만 반영하고 원격 파일과 CI를 확인한다. 기존 사용자 서버, Docker, 참조 프로젝트를 변경하지 않는다.

## 검증 기록 (2026-10-19)

전체 프런트 단위 테스트 106개 통과. 브라우저에서 14개 용어와 14개 카테고리 소속 연결선, 키보드/드래그 회전, 줌, 같은 카테고리 3개 선택, 기존 초안 보존과 중복 추가 방지, 검색 후 선택 유지, 모바일 목록, 가로 넘침 없음을 확인했다. Demo production에서 키보드 선택·검색·샘플 전송·과거 답변 갤러리 복귀를 확인했으며 외부/API 요청은 0건이었다.

WebGL context를 반환하지 않는 모바일 브라우저와 reduced motion 환경에서 터치 회전·핀치 및 한 손가락으로의 전환, 노드 탭·입력 추가·목록 선택을 확인했다. 독립 리뷰가 발견한 핀치 종료 시 남은 포인터 처리 문제는 최신 시점과 좌표로 기준을 재설정하고 중복 lostpointercapture를 무시하도록 수정했다. CDP 제스처와 Playwright tap을 혼합하면 제품 코드 없는 HTML에서도 click이 누락되어, 실제 제스처 검증과 탭 검증은 각각 새 context에서 실행했다.

그래프는 실제 XYZ를 투영하지만 WebGL mesh나 물리 시뮬레이션은 사용하지 않는다. 다른 카테고리 사이 연결, 의미 유사도, 자동 추천은 표시하지 않는다. 목록은 동일한 14개 데이터와 선택 상태를 사용한다. 생산 코드에 외부 서비스·추가 패키지·상시 애니메이션 루프를 추가하지 않았다.

Demo/live production 빌드 모두 통과했다. Live mock 브라우저에서도 기존 초안에 같은 카테고리 두 용어 추가, 홈 복귀 시 선택 유지, `body_inverted_triangle`만 기존 term-search API로 보내는 경로를 확인했다. 실제 외부 요청·모델 생성 호출은 0건이었다. 백엔드는 변경하지 않았으며 기존 원격 전체 CI를 후속 확인한다.
