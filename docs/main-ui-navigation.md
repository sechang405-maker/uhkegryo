# 메인 하단과 브라우저 화면 이력

## 변경 범위

- 그래프의 회전·확대축소·배율·초기화는 기본 접힘 상태의 `그래프 조작` 안에 유지한다. 긴 조작 안내는 `조작 도움말`로 접는다. 네이티브 details/summary를 사용해 키보드와 보조 기술의 열기/닫기 동작을 유지한다.
- 선택한 용어가 있을 때만 칩과 `선택 N개 입력에 추가`를 표시한다. 중복 빈 선택 안내는 제거한다. 추가 성공·한도 오류의 상태 알림은 유지한다.
- 기존 쿠키·로컬 프로필·데모 기록 복원 안내를 기록 패널로 이동한다.
- Enter 안내는 761px 이상에서 입력창에 초점이 있을 때만 보인다. 모바일에서는 숨긴다. 글자 수는 450자부터 표시하며, 항상 연결된 접근성 설명으로 500자 한도를 제공한다. 초과 입력은 오류와 aria-invalid로 안내하고 전송을 막는다.

## 화면 이력

검색, 답변 선택, 기록 세션 전환, 새 세션 및 홈 이동은 실제 브라우저 이력에 연결한다. 같은 화면을 다시 선택하면 이력을 중복 추가하지 않으며, popstate에서는 이력을 추가하지 않는다. Next가 사용하는 기존 history 필드는 보존한다.

브라우저 이력에는 무작위 범위와 항목 ID만 저장한다. 입력·선택·결과·세션·이미지 검색 모드와 복구 예산은 현재 페이지 메모리에서 복원한다. 뒤로/앞으로 가기는 이미 완료된 검색을 재실행하지 않는다. 삭제한 세션의 스냅샷은 무효화한다.

직접 진입과 새로고침은 현재 항목만 초기화하며 별도의 이탈 방지 항목을 추가하지 않는다. 새로고침으로 메모리 스냅샷이 사라진 오래된 앱 이력은 홈으로 복귀한다. 최초 항목을 넘는 뒤로가기는 브라우저의 정상 이동을 허용한다.

복원 시 진행 중인 화면 조회와 클라이언트 전송 대기를 취소하며, 오래된 응답/실패가 복원 화면이나 새 전송 상태를 덮지 않도록 보호한다. 이는 서버에 이미 접수된 작업을 삭제하거나 취소하는 동작이 아니다. 같은 세션의 다른 완료 답변을 보는 동안 접수된 작업은 대화에 추가하고 폴링을 유지하며 선택한 갤러리는 보존한다.

## 검증

- `cd frontend && npm test`: 136개 통과.
- `npm run build`: production 빌드 통과.
- `node tests/browser/main-footer.cjs`: 데스크톱/모바일 접기 반복, 키보드 포커스, 목록, 선택/해제/추가/검색, 초점 안내, Unicode 글자 수와 초과 오류, 기록 패널 안내.
- `node tests/browser/screen-history.cjs`: 검색→결과→뒤로→앞으로, 초안/선택 복원, 초기 기록 결과→홈, 기록 답변/세션 전환, 모드 복원, 중복 이력 방지, 새로고침, 정상 이탈, 대기 중 전송 복원과 접수 작업 유지.
- `node tests/browser/graph-wheel.cjs`: 휠 확대 비활성, 기본 스크롤, 드래그, 접힌 조작 안의 확대 버튼.
- 기존 3D 브라우저 검증에서 36개 노드의 깊이·드래그·키보드·초기화·모바일 핀치를 확인한다.

브라우저 검사는 API를 로컬 가상 응답으로 대체한다. 유료 API·실제 기록 변경·외부 이미지 업로드를 실행하지 않는다. `APP_BASE`, `PLAYWRIGHT_MODULE`, `CHROMIUM_EXECUTABLE`로 로컬 검증 환경을 지정할 수 있다. 브라우저 검사는 Node 단위 테스트 glob에 포함되지 않으므로 별도 실행한다.
