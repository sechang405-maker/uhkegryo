# 검색 기록의 텀카드 제목

검색 기록 목록은 가장 최근 완료 결과 중 카드가 있는 결과의 `label_ko`를 연결해 표시한다. 날짜는 보존하고 툴팁에서 확인할 수 있다. 저장된 이름이 없는 기록은 카드 ID로 현재 카탈로그의 이름을 복원한다. 알 수 없는 카드는 `이름 없는 텀카드`, 카드 자체가 없는 기록은 `검색 기록`으로 표시한다. 사용자 원문을 제목으로 노출하지 않는다.

목록 조회의 소유자·만료·페이지 조건을 유지하며 기존 JSON 결과를 읽기만 한다. 스키마 변경과 데이터 재작성은 없다. 완료된 새 결과는 목록 제목을 갱신한다. 데모도 저장된 fixture ID에서 카드 이름을 복원한다. 긴 이름은 두 줄로 제한하지만 전체 이름은 접근성 텍스트와 툴팁에 남는다.

검증: 복수 이름, 긴 이름, ID fallback, 빈 기록, 목록 갱신, 데모 복원 단위 테스트. 브라우저 fixture에서 이름 표시·기록 선택·삭제·모바일 확인. PostgreSQL 통합 테스트는 별도 테스트 DB가 있을 때 실행되며 사용자 DB에 fixture를 쓰지 않는다.
