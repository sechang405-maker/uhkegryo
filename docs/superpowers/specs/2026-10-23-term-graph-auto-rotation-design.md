# 3D 그래프 자동 회전 설계

상태: 사용자 승인 구현 범위

## 목표

- 메인 3D 그래프는 처음 표시될 때 수직축으로 120초에 한 바퀴 회전한다.
- 기존 월드 좌표, 투영, 깊이 합성, 노드/엣지 배치와 사용자 확대·축소 동작은 변경하지 않는다.
- 포인터 이동이 기존 드래그 임계값 5px를 넘거나 두 손가락 제스처가 시작되면 자동 회전을 즉시 영구 중지한다.
- 단순 클릭, 노드 선택, 펼침, 휠 확대·축소와 재렌더는 자동 회전을 중지하거나 재시작하지 않는다.

## 구조

- 자동 회전 시간 계산은 순수 함수 모듈로 분리한다. 입력은 이전 프레임 시간, 현재 시간, 활성 여부이며 출력은 제한된 delta와 yaw 증가량이다.
- 기존 `TermGraph`의 RAF 루프 하나가 펼침/접힘 애니메이션과 자동 회전을 함께 구동한다. 별도 루프와 CSS 회전은 만들지 않는다.
- 자동 회전 중지 상태는 컴포넌트 수명 동안 유지한다. 그래프 데이터 변경이나 노드 확장으로 초기화하지 않는다.
- `document.hidden` 및 `prefers-reduced-motion: reduce`에서는 자동 회전을 수행하지 않으며, 재개 시 숨겨진 시간은 delta에 포함하지 않는다.
- delta는 상한을 두어 탭 복귀나 일시적인 프레임 지연으로 큰 회전 점프가 발생하지 않게 한다.
- unmount 시 기존 RAF와 이벤트 리스너를 정리한다.

## 검증

- 순수 타이머 테스트: 120초당 2π, 프레임 속도 독립, 큰 delta 제한, pause 후 기준 시간 재설정.
- 컴포넌트 연결 테스트: 기존 RAF 재사용, reduced-motion/visibility 조건, 5px 미만 클릭 유지, 드래그·터치 시 영구 중지, cleanup.
- 기존 그래프 모션·배치·깊이·개인 용어 테스트와 프로덕션 빌드 회귀.

## 비범위

- 자동 회전 속도 UI, 자동 재개 버튼, 관성 회전, 카메라 또는 노드 배치 변경은 추가하지 않는다.
