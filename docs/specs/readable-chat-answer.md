# 읽기 편한 통합 답변

## Why
긴 통합 답변을 한 문단에 표시하면 좁은 채팅창에서 읽기 어렵다.

## Goal
브랜드 스타일과 답변 내용은 유지하면서 문단·글자 크기·여백을 개선한다.

## What
- 답변 16px / 일반 굵기 / 줄 간격 1.7 / 짙은 회색.
- 빈 줄은 별도 문단으로 표시하고 문단 간격은 14px.
- 초기 구현은 응답 reference_plan의 한국어 용어가 본문에 처음 등장할 때만 강조했다. 후속 Markdown 표시에서는 LLM이 작성한 강조를 따른다.
- 답변 패딩 20px, 사용자 말풍선은 14px로 유지.
- 초기 구현의 범위는 Markdown 파싱을 제외했다. 현재 Markdown 지원은 markdown-answer-rendering.md가 정의하며 원시 HTML은 허용하지 않는다.

## How
순수 표시 함수로 문단과 강조 구간을 만들고 React 텍스트 노드 및 strong으로 렌더한다.
위 방식은 초기 구현 기록이다. 현재 ConversationPanel은 MarkdownAnswer로 교체했고 기존 표시 함수와 테스트는 제거했다.

## AC
- LF/CRLF 빈 줄과 공백 줄을 문단 경계로 처리하고 단일 줄바꿈은 유지한다.
- 초기 구현은 중복 용어의 최초 강조와 HTML 텍스트 유지를 검사했다. 현재 강조·HTML 정책은 markdown-answer-rendering.md를 따른다.
- 실제 답변의 font-size 16px, line-height 27.2px 및 문단 간격 14px.
- 테스트·빌드·diff 검사 통과, 기존 기록으로 UI 확인. 새 유료 호출 없음.

## 검증 결과
- 프론트 테스트 48개 및 production build 통과.
- 기존 답변에서 실제 16px / 400 / 27.2px 줄 간격과 한국어 용어 두 개의 최초 강조를 확인했다.
- 빈 줄 문단 분리·단일 줄바꿈 유지·HTML/Markdown 원문 유지는 단위 테스트로 확인했다. 현재 실제 기록은 빈 줄이 없어 다중 문단 화면은 별도 실측하지 않았다.
- 답변 내용을 다시 생성하거나 기존 기록을 수정하지 않았다.
