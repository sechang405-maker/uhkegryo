# 레퍼런스 이미지 확대 보기

## Why
작은 썸네일의 자세와 디테일을 화면을 떠나지 않고 살펴본다.

## Goal
썸네일 클릭으로 확대창을 열고 원래 핀 링크를 별도로 제공한다.
고해상도 원본 수집·이미지 생성·다운로드 기능은 제외한다.

## What
이미지를 누르면 제목·확대 이미지·핀 원본 열기·닫기가 있는 모달을 표시한다.
닫기 버튼, 바깥 클릭, Escape로 닫는다. 실패한 썸네일은 확대 버튼으로 표시하지 않는다.
확대 이미지 로딩 실패 시 안내와 핀 링크를 유지한다.

## How
기존 thumbnail_url과 pin_url을 사용한다. native dialog.showModal로 배경 접근과 포커스를 제한한다.
닫힌 뒤 클릭했던 썸네일 버튼으로 포커스를 돌린다. 새 API나 외부 이미지 요청 대상을 추가하지 않는다.

## AC
- Given 표시된 썸네일, When 클릭, Then 같은 URL의 이미지를 자르지 않고 확대 표시한다.
- Given 확대창, When 닫기·바깥 클릭·Escape, Then 닫히고 원래 버튼에 포커스가 돌아온다.
- Given 확대창, When 핀 원본 열기 확인, Then 기존 pin_url을 새 탭 링크로 제공한다.
- Given 이미지 로딩 실패, When 오류 발생, Then 실패 안내와 원본 링크가 유지된다.
