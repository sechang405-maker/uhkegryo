# 통합 답변 Markdown 표시

## Why
LLM의 문단·제목·강조·목록·주의 인용을 읽기 쉽게 표시한다.

## Goal
answer_text 문자열 계약은 유지하고 안전한 Markdown 렌더러로 표시한다.

## What
- 제목, 굵게, 기울임, 목록, 인용, 문단을 지원한다.
- 원시 HTML은 무시하고 링크는 글자만, 이미지·iframe은 표시하지 않는다.
- 자동 용어 강조 대신 LLM이 작성한 강조를 따른다. 기존 일반 텍스트도 표시한다.
- 기본 텀카드 안내·사용자 메시지는 기존 텍스트 표시를 유지한다.

## How
react-markdown 10의 허용 요소 목록과 skipHtml을 사용한다. raw HTML 플러그인은 넣지 않는다. 제목·목록·인용은 기존 브랜드 스타일과 16px 본문에 맞춘다.

## AC
- Given Markdown, Then 제목·강조·목록·인용이 실제 태그로 표시된다.
- Given HTML/이미지/위험 링크, Then 실행·이미지 요청·클릭 가능한 링크를 만들지 않는다.
- Given 일반 텍스트, Then 내용을 유지한다.
- 프론트 테스트와 빌드가 통과한다. 유료 LLM 호출 없이 렌더링을 검증한다.

## 검증 결과
- 프론트 테스트 51개 통과. 분리된 OSC20 브랜치의 production build 통과.
- React 실제 렌더러를 이용한 제목·굵게·목록·인용·일반 텍스트 및 위험 요소 차단 테스트 통과.
- 원래 3002 실행 폴더에도 동일한 컴포넌트·의존성을 적용했다.
- 새 라이브 LLM 응답의 화면 표시는 미검증이다. 기존 답변·DB 기록을 다시 생성하거나 수정하지 않았다.
