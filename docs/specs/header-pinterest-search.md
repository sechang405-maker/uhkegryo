# 상단 Pinterest 검색 버튼 배치

## Why
추천 검색어를 복사하는 대신 바로 Pinterest에서 검색한다.

## Goal
복사 버튼을 없애고 검색어 오른쪽에 기존 Pinterest 검색 버튼을 배치한다.

## What
검색 링크, 새 탭 열기, 알고리즘 차이 안내와 브랜드 스타일은 유지한다.
검색어와 버튼은 간격 없이 붙이고 바깥 모서리만 둥글게 처리한다. 접합부 테두리는 중복되지 않는다.

## How
상단 JSX에서 링크를 검색어 뒤로 이동하고 사용하지 않는 복사 상태·타이머·핸들러와 버튼 CSS를 제거한다.

## AC
- 상단에는 검색어와 오른쪽 Pinterest 버튼만 표시되며 복사 버튼은 없다.
- 검색어와 버튼 사이에는 여백이 없으며 하나의 연결된 영역으로 표시된다.
- 링크의 q 값은 현재 추천 검색어이며 새 탭으로 열린다.
- 기존 프론트 테스트 및 빌드가 통과한다.
