# 보드 탐색 메뉴

## Why
검색 결과를 보던 사용자가 TERM_CARD 홈과 이전 검색을 다시 확인해야 한다.

## Goal
브랜드 아이콘에서 홈·기록 메뉴를 열고 이전 결과를 다시 표시한다.
서버 이력 조회 및 새로고침 이후 기록 복원은 이번 UI 범위 밖이다.

## What
로고와 브랜드 이름 전체가 하나의 메뉴 버튼이다. 누르면 같은 너비의 직사각형 메뉴가
상단 경계에 붙어 240ms 동안 아래로 펼쳐지고, 닫을 때 같은 시간 동안 위로 접힌다.
닫는 즉시 클릭·키보드 접근을 차단하며 애니메이션 이후 숨긴다. 동작 줄이기 설정에서는 애니메이션을 생략한다.
메뉴의 상단 위치는 고정하며 표시 범위만 변경해 애니메이션 중 헤더를 침범하지 않는다.
홈·기록 항목은 동일한 크기를 사용한다. 홈은 부채꼴 TERM_CARD 화면,
기록은 현재 탭에서 접수한 검색 목록을 표시한다. 기록을 선택하면 해당 결과로 돌아간다.
메뉴 바깥 클릭 또는 Escape로 닫힌다. 기록이 없으면 빈 상태를 표시한다.
홈 부채꼴 중앙도 상단과 같은 UH 브랜드 아이콘 버튼이며, 같은 상단 홈·기록 메뉴를 연다.
Escape로 닫으면 메뉴를 열었던 브랜드 버튼으로 포커스를 돌린다.

## How
React 상태로 화면과 기록을 관리한다. 요청 원문과 완료 결과는 메모리에만 보관하며
localStorage에 저장하지 않는다. 신규 API를 추가하지 않는다.
데모 최초 기록은 미리보기임을 표시한다. 새 검색은 결과 화면으로 전환한다.
홈의 카드 선택과 결과의 스크롤 검색어 동작은 각 화면에서 유지한다.

## AC
- Given 결과 화면, When 아이콘과 홈을 선택, Then 부채꼴 TERM_CARD 화면이 표시된다.
- Given 메뉴 열림, When 바깥 클릭 또는 Escape, Then 메뉴가 닫힌다.
- Given 현재 탭 검색 기록, When 기록 선택, Then 원문 목록이 표시된다.
- Given 완료된 기록, When 항목 선택, Then 해당 결과와 요청이 표시된다.
- Given 홈에서 새 검색, When 요청 접수, Then 결과 화면으로 전환한다.
- Given 홈 부채꼴, When 중앙 브랜드 아이콘을 클릭하거나 Enter로 선택, Then 기존 홈·기록 메뉴가 열린다.
