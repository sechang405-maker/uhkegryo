# 읽기 쉬운 레퍼런스 썸네일 배치

## Why
- 그림의 체형·포즈를 관찰하는 사용자가 112px 기본 너비의 작은 썸네일을 보기 어렵다.

## Goal
- 카드 너비를 240~320px 범위로 확대하고 여러 줄로 표시한다.
- 이미지 비율과 전체 갤러리 스크롤을 유지한다.
- 범위 밖: 이미지 수, 검색 API, 채팅, 브랜드 스타일 변경.

## What
- 가용 너비에 따라 카드가 다음 줄로 넘어간다.
- 이미지 높이에 따라 카드와 카테고리 영역이 늘어난다.
- 240px보다 좁은 영역에서는 카드가 컨테이너 너비에 맞게 축소되어 가로 넘침을 막는다.

## How
- `frontend/app/globals.css`의 `.pin-gallery-items`를 auto-fill grid로 변경한다.
- 열 최소 너비는 `min(240px, 100%)`, 최대 너비는 `1fr`로 하고 카드 최대 너비는 320px로 제한한다.
- 모바일의 112px flex-basis와 가로 스크롤 override를 제거한다.
- 이미지는 기존 `width: 100%; height: auto`를 유지한다. 원본 픽셀 크기를 강제하거나 잘라내지 않는다.
- 색상, 폰트, 테두리, 확대 보기와 스크롤 기반 카테고리 선택은 유지한다.

## AC
- Given 8개 핀, When 데스크톱 갤러리 표시, Then 여러 줄로 배치되고 카드 너비는 240~320px이다.
- Given 세로·가로 이미지, When 표시, Then 원본 비율을 유지하고 카드 및 카테고리 높이가 콘텐츠에 맞는다.
- Given 좁은 모바일 화면, When 표시, Then 갤러리 가로 넘침이 없고 카드가 컨테이너 안에 들어간다.
- Given 기존 프론트 기능, When 테스트·빌드, Then 기존 테스트와 빌드가 통과한다.

## 실행 계획 및 검증
- 승인된 여러 줄 배치로 최소 CSS 변경 → 프론트 테스트 및 빌드 → 실제 핀 화면의 너비·줄바꿈·이미지 비율·스크롤 확인.
- 2026-10-02 최소 CSS 변경 완료. 프론트 테스트 45 passed, production build 통과, `git diff --check` 통과.
- 실제 성공 검색 기록의 16개 썸네일로 확인했다. 변경 전 첫 8개 카드가 112px·같은 y좌표였고, 변경 후 약 242px·4개 행으로 배치됐다.
- 이미지 16개 로드 및 원본 비율 유지 확인. 첫 카테고리 높이가 약 1763px로 콘텐츠에 맞춰 늘어났다.
- 실제 레이아웃 너비 300px의 좁은 화면에서 카드 약 242px, 갤러리·페이지 가로 넘침 없음 확인.
- 전체 갤러리 스크롤로 포즈 영역 도달 및 상단 검색어의 콘트라포스토 전환 확인. 테스트용 viewport는 원래대로 복구했다.
- API·LLM·카드 데이터는 수정하지 않았다. 기존 backend 답변 지침 변경은 별도 작업으로 보존했다. 커밋·push는 수행하지 않았다.
