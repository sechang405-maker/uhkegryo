# 반복된 새 레퍼런스 요청의 메모리 의도 분류 보완

## Why
- 시연자가 이전과 같은 레퍼런스 요청을 다시 제출하면 LLM이 과거 회상으로 오분류해 인용 검증 실패로 종료된다.
- 지표: 기존 대화에서 반복된 일반 요청의 첫 시도 완료 여부.
## Goal
- 이전 기록과 문장이 겹쳐도 현재 레퍼런스 요청은 none으로 분류한다.
- 범위 밖: 인용 검증 완화, 키워드 기반 서버 라우팅, 기존 기록 수정.
## What
- 새 검색/포즈 변경은 none, 과거에 무엇을 요청하거나 추천했는지 묻는 경우만 recall이다.
- 실제 회상과 새 검색을 동시에 명시한 요청만 mixed다.
## How
- memory classify의 system 지침에 반복 요청과 실제 회상 질문의 대조 예시를 추가한다.
- 기존 RecallQuery 스키마와 원본 인용 검증, 재시도 상한을 유지한다.
## AC
- Given 이전과 같은 일반 레퍼런스 요청이 있는 대화, When 같은 요청 재제출, Then 회상 인용 오류 없이 새 검색이 완료된다.
- Given 실제 과거 추천 질문, When 분류, Then 기존 recall 계약이 유지된다.
