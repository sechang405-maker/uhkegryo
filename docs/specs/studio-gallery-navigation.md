# Studio 갤러리·메뉴·검색어 표시

## Why
여러 레퍼런스를 카테고리별로 확인하면서 검색어를 복사하고 핀 원본을 열어야 한다.

## Goal
홈/기록 메뉴, 카테고리별 8개 썸네일, 원본 비율 확대, 스크롤에 따른 검색어 갱신을 제공한다. 별도 검색 API 호출은 후속 PR이다.

## What
로고와 중앙 UH 버튼은 메뉴를 연다. 홈은 부채꼴 탐색, 기록은 현재 탭의 완료/실패 요청을 표시한다. 카테고리 영역 전체를 스크롤하며 가장 가까운 행의 검색어를 표시한다. 복사됨은 3초 후 해제한다. 이미지 실패는 해당 핀에 안내한다.

## How
기존 결과 모델과 local state를 사용한다. clipboard, native dialog, AbortController를 후속 검색 연결에 사용한다. Pinterest 링크는 추천 검색어로 구성하되 개인화로 결과가 달라질 수 있음을 안내한다. 이 단계의 카드 클릭은 이미 있는 결과를 표시하며 새 검색하지 않는다.

## AC
- Given 메뉴, When 로고 또는 UH 클릭, Then 홈/기록 선택지가 나타난다.
- Given 결과 행, When 스크롤, Then 활성 카테고리의 검색어가 헤더에 표시된다.
- Given 카드의 핀, When 클릭, Then 확대 대화상자와 원본 링크를 표시한다.
- Given 복사 성공, When 3초 경과, Then 복사 버튼이 원래 문구로 돌아온다.
- Given 핀 이미지 실패, When 표시, Then 다른 핀과 요청 기록을 유지한다.
