# 홈 텀카드 용어 안내

## Why
홈 예시를 누른 초보자가 레퍼런스뿐 아니라 검수된 뜻과 관찰 포인트를 바로 확인해야 한다.

## Goal
홈 텀카드 선택 시 기존 검색과 함께 대화창에 별도의 UH · 용어 안내를 표시한다.

## What
- 자체 DB의 한국어 용어, 쉬운 뜻, 관찰 포인트, 혼동 주의 사항을 그대로 표시한다.
- 최신 클릭 한 건만 표시한다. 홈 이동·기록 선택·유효한 새 대화 제출 시 안내를 지운다.
- 안내는 일시 UI 상태이며 turns, localStorage, 서버 대화, 검색 기록에 넣지 않는다.
- 검색 실패와 관계없이 설명을 표시한다. LLM 생성 답변으로 표시하지 않는다.
- 모바일에서는 안내를 볼 수 있도록 대화 탭으로 이동한다.

## How
홈 카탈로그의 feedback에서 주의 사항도 읽고 별도 TermGuide 컴포넌트를 대화 아래 표시한다. 기존 term-search 호출은 유지하며 추가 API 호출은 없다.

## AC
- Given 홈 카드, When 클릭, Then 검수된 뜻·관찰점·주의 사항이 UH · 용어 안내로 표시된다.
- Given 다른 카드, When 클릭, Then 안내는 교체되며 실제 대화와 검색 기록은 증가하지 않는다.
- Given 검색 실패, Then 카드 안내는 유지되고 이미지 검색 실패 안내는 별개로 표시된다.
- Given 모바일, When 카드 클릭, Then 대화 탭에서 안내를 바로 볼 수 있다.
- Given 홈/기록/새 대화, When 이동·제출, Then 일시 안내는 제거된다.

## 검증 결과
- 프론트 테스트 51개, production build 및 diff 검사 통과.
- 콘트라포스토 클릭 시 검수된 뜻·관찰점·주의 사항 즉시 표시, 홈 이동 시 안내 제거 확인.
- 390px에서 역삼각형 클릭 후 대화 탭 자동 전환 확인. 안내 1개, 기존 대화 2건·기록 2건 유지.
- 실제 핀 검색 8개 복원 확인. LLM 호출 및 사용자 메시지 전송은 하지 않았다.
- 검색 실패 시 안내 유지와 새 대화 제출 후 제거는 코드 경로를 확인했으나 실제 장애·유료 전송으로 재현하지 않았다.
- 미리보기는 OSC20 worktree의 localhost:3003에서 진행했다. 원래 3002 서버와 작업 폴더는 유지했다.
