# 해석 프롬프트 v3 경계 단서

## Why

- 페르소나: 모호한 표현으로 캐릭터 레퍼런스를 요청하는 사용자.
- 상황: v2와 `gpt-4.1-mini` 평가에서 상충 조건은 질문했지만 인상 표현과 의상 효과를 카드 근거로 오인했다.
- 문제: 몸이 휘어 보인다는 인상만으로 특정 포즈를, 옷 때문에 넓어 보이는 어깨만으로 체형을 확정할 수 없다.
- 측정 지표: EVAL-12·13·14의 금지 카드 선택 0건, 전체 30문항 회귀 수.

## Goal

- 불충분한 포즈·의상 효과·시점과 원근 단서의 경계를 명확히 한다.
- 같은 모델·평가셋으로 v2 대비 회귀를 측정한다.
- Out of Scope: 카드 데이터 수정, resolver 완화, 평가 기대값 변경.

## What

- 체중 지지와 몸통 곡선이 불명확한 인상 표현은 질문한다.
- 넓은 어깨가 의상 때문일 수 있으면 체형을 추측하지 않고 질문한다.
- 광각이라는 말만으로 신체 단축이나 3점 투시를 선택하지 않는다.
- 기존 출력 JSON 계약과 정확한 근거 인용은 유지한다.

## How

- v2 프롬프트를 복사해 v3의 단서별 결정 규칙을 추가한다.
- `INTERPRETER_PROMPT_PATH`와 `INTERPRETER_PROMPT_VERSION`으로 평가 후보를 지정한다.
- 경계 문항을 먼저 확인하고 전체 30문항으로 회귀를 확인한다.

## AC

- GIVEN: 체중 지지 여부가 빠진 인상 표현 WHEN: 해석한다 THEN: 특정 포즈를 단정하지 않고 질문한다.
- GIVEN: 의상이 어깨를 넓어 보이게 한다 WHEN: 해석한다 THEN: 체형을 선택하지 않고 실제 비율을 묻는다.
- GIVEN: 광각 느낌이나 낮은 시점만 있다 WHEN: 해석한다 THEN: 손·발의 명시적 단축 없이 `perspective_foreshortening`을 선택하지 않는다.
- GIVEN: 고정 30문항 WHEN: v3를 평가한다 THEN: v2와 실패 문항·호출 수를 비교한다.
