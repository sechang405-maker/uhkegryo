# 카테고리별 도형화 검색

## Why
스케치 결과 대신 인체를 기본 입체 도형으로 나눈 레퍼런스를 찾고 싶은 사용자를 돕는다.

## Goal
현재 텀카드에만 mannequinization 접미사로 재검색한다. 설명·다른 카테고리·카드 DB는 변경하지 않는다.

## What
각 결과 행의 `일반 · 스케치 · 도형화`에서 도형화를 선택한다. 스케치 적용 뒤에도 사용할 수 있으며 직접 도형화 검색도 가능하다. 일반 재검색과 도형화 도움말은 category-search-modes.md를 따른다.
행당 동시 요청은 하나다. 성공 시 해당 행의 이미지·검색어만 교체한다. 실패·빈 결과면 이전 성공 결과를 유지하고 재시도할 수 있다.
홈·기록·새 검색 이동 시 진행 중 요청을 취소한다. 별도 검색 기록은 저장하지 않는다.
대화 더미 화면에서도 도형화 재검색은 실제 API를 호출한다. 실패 시 이전 이미지를 유지하지만 새 검색 성공으로 표시하지 않는다. 실제 검색 품질 향상을 보장하지 않는다.

## How
POST /api/term-search의 suffix 허용값을 drawing|sketch|mannequinization으로 확장한다. 기본 drawing은 유지한다.
카탈로그 query_fragments는 그대로 두고 마지막 접미사만 변경한다.
기존 term_id별 재검색 상태와 취소 처리를 재사용한다. 요청 중 해당 행의 버튼을 비활성화하고 완료 뒤에는 같은 모드도 다시 검색할 수 있다.
활성 행의 상단 검색어·복사·Pinterest 링크도 새 검색어를 사용한다.

## AC
- Given 스케치 결과, When 도형화 검색 성공, Then 검색어는 mannequinization으로 끝나며 해당 행 이미지만 변경된다.
- Given 재검색 실패, When 응답 수신, Then 이전 이미지·검색어·설명을 유지하고 재시도가 가능하다.
- Given 요청 중, When 홈 이동, Then 늦은 응답은 화면을 바꾸지 않는다.
- Given 지원하지 않는 suffix, When API 호출, Then 422이며 provider를 호출하지 않는다.
- Given 기본 또는 sketch 요청, When 검색, Then 기존 접미사 동작을 유지한다.
