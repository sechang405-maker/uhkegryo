# 홈 텀카드 단일 탐색

## Why
초보자가 설명을 입력하지 않아도 홈의 용어를 눌러 해당 레퍼런스를 탐색한다.

## Goal
클릭한 카드 하나의 고정 검색어·최대 8개 핀을 표시한다. 우측 통합 대화는 유지한다.
LLM 호출·job 생성·세션 및 검색 기록 저장은 하지 않는다. 홈 복귀 시 부채꼴을 유지한다.

## What
카드 클릭은 검색어 선택과 단일 결과 열기를 함께 수행한다. 검색 중에는 로딩을 표시한다.
실패 시 기존 대화와 즉시 검색은 유지하고 이미지 영역에 실패 안내를 표시한다.
빠르게 다른 카드를 선택하거나 홈·기록·새 검색으로 이동하면 이전 응답을 적용하지 않는다.
개발 데모는 기존 더미 핀을 사용하며 미리보기로 표시한다.

## How
POST /api/term-search: {term_id: string(1~120), suffix?: drawing|sketch} → TermResult. 기본 접미사는 drawing이며 카테고리별 스케치 재검색은 별도 명세를 따른다.
서버 카탈로그의 활성 ID만 허용한다. 임의 검색어·URL은 받지 않는다.
직접 검색 금지 카드는 409, 없는 ID는 404, 스키마 오류는 422를 반환한다.
기존 GooglePinSearchProvider + PinterestWidgetProvider를 사용한다.
동시 검색은 프로세스당 2건, 추가 요청은 429. 전체 도구 timeout은 25초이며 실패는 PIN_SEARCH_UNAVAILABLE로 반환한다.
읽기 전용이며 DB·LLM·영속화 함수는 호출하지 않는다. 운영 전 분산 rate limit은 별도 필요하다.
UI는 단일 탐색 상태를 기존 job/history 상태와 분리한다. 검색어는 서버 search_url에서 복원한다.

## AC
- Given 홈 카드, When 클릭, Then 해당 카드만 결과로 표시하고 검색어를 갱신하며 우측 대화는 변경하지 않는다.
- Given 단일 탐색, When 완료 또는 실패, Then 검색 기록 수는 변하지 않는다.
- Given 검색 중, When 홈 이동 또는 새 카드 선택, Then 이전 응답은 새 화면을 덮어쓰지 않는다.
- Given 검색 실패, When 결과 표시, Then 기존 대화·즉시 검색을 유지하고 이미지 영역에 실패 안내를 제공한다.
- Given 잘못된 ID/직접 검색 금지 ID, When API 호출, Then 도구를 호출하지 않는다.
